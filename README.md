
# Website Ludmila Faria

This is the professional website of lawyer Ludmila Faria, specializing in Compliance, Digital Law, and Data Protection, providing legal services for companies and individuals in Europe and Brazil.

## Project Structure
- **index.html**: Home page
- **html/**: Internal pages (About, Contact, Privacy Policy)
- **css/**: Stylesheets
- **js/**: JavaScript scripts
- **assets/**: Images and icons

## Features
- SEO optimized (meta tags, Open Graph, keywords)
- Accessibility improvements (alt text for images)
- Responsive design
- English content for international visitors
- Legal expertise in compliance, digital law, and data protection
- Seamless email capture powered by [Getform.io](https://getform.io)

## How to view the site 
1. Download or clone this repository.
2. Open the `index.html` file in your browser.

## Technologies Used
- HTML5
- CSS3
- JavaScript
